# Wildlife Trafficking Listings

An applied data science project studying wildlife-trafficking indicators in
online marketplace listings. The project analyzes the VIDA-NYU/LTS shark
trophy and leather listing datasets, then presents the findings in a
self-contained, navigable HTML report.

## Project contents

| File or directory | Purpose |
| --- | --- |
| `analysis.py` | Runs the analyses for syllabus Modules 1–6 and saves computed results and figures. |
| `build_site.py` | Builds the HTML report using `results.json`, `figures/`, and code sections from `analysis.py`. |
| `site.css` | Report styles, including responsive layouts and light/dark color themes. |
| `index.html` | Generated report. Open it in a browser; the charts are embedded in the page. |
| `results.json` | Generated statistics and model results consumed by the report builder. |
| `figures/` | PNG charts generated by the analysis. |
| `requirements.txt` | Python dependencies for the analysis. |

## Requirements

- Python 3
- Git
- The CSV files from the [VIDA-NYU/LTS repository](https://github.com/VIDA-NYU/LTS)
- Packages listed in `requirements.txt`

Install the Python dependencies from the project root:

```bash
python -m pip install -r requirements.txt
```

## Get the data

Clone the public VIDA-NYU/LTS repository alongside this project (or choose
another location):

```bash
git clone https://github.com/VIDA-NYU/LTS.git
```

The analysis expects these files in the repository's `data_use_cases/`
directory:

- `shark_trophy.csv`
- `validation_sharks.csv`
- `data_leather.csv`
- `leather_validation.csv`

If the data is somewhere else, set `DATA_DIR` to the directory containing
those four files. The default is `data_use_cases` relative to the current
working directory.

## Run the project

Run these commands from the project root, in order. The analysis reads the CSV
files, writes `results.json` and chart images into `figures/`; the report
builder then embeds those outputs and the analysis code in `index.html`.

### Windows PowerShell

```powershell
$env:DATA_DIR = "..\LTS\data_use_cases"
python analysis.py
python build_site.py
```

Adjust the `DATA_DIR` path if you cloned the dataset to a different location.

### macOS or Linux

```bash
DATA_DIR=../LTS/data_use_cases python analysis.py
python build_site.py
```

Open `index.html` in a web browser to read the report. Its charts are embedded,
so the generated page does not need the image files at viewing time. Google
Fonts are loaded from the web; system font fallbacks are used if they are
unavailable.

## Analysis overview

The report covers six modules:

1. Data profiling, preparation, text classification, cross-validation, and
   bootstrap evaluation.
2. Descriptive statistics and exploratory analysis.
3. Inferential statistics and hypothesis testing.
4. Regression modelling and diagnostics.
5. Anomaly detection and data-quality outliers.
6. Time-series analysis.

Model evaluation accounts for the imbalance in the shark-product labels and
reports measures such as F1, precision, recall, and average precision. A
fixed random seed (`42`) is used for the project's randomized steps.

See the report's **Limitations & Coverage** section for dataset constraints,
analysis decisions, and work that was not performed. In particular, the
analysis uses the four CSV files from the public repository; it does not
include additional Drive-only data or image analysis.
