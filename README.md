# Applied Data Science: Wildlife-trafficking listings (VIDA-NYU/LTS)
- `analysis.py`: runs every task (Modules 1-6), writes `results.json` and `figures/`
- `build_site.py` + `site.css`: generate `index.html` (self-contained) from those outputs
- Data: CSVs in https://github.com/VIDA-NYU/LTS (`data_use_cases/`); run `DATA_DIR=LTS/data_use_cases python analysis.py`
- Seed 42 throughout. See the "Limitations & Coverage" section of the site for what was not done.
